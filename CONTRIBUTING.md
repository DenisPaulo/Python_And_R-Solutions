# Contribuindo

Obrigado pelo interesse em **python-and-r-solutions**! Este é um projeto acadêmico/de portfólio (CRUD em Python e estatística/clima em R).

## Como sugerir melhorias

- **Ideias e problemas:** abra uma [issue](https://github.com/DenisPaulo/python-and-r-solutions/issues) explicando o que você observou ou propõe.
- **Código ou documentação:** faça um fork, crie uma branch, e abra um Pull Request descrevendo a mudança. Prefira PRs pequenos e focados.

## Como rodar localmente

Para rodar localmente, siga a seção "Como executar" do [README](README.md).

## Antes de abrir o PR

Execute `farmtech.py` e/ou os scripts em R que você alterou e confira o resultado manualmente.

Não inclua segredos, credenciais ou dados pessoais no código, nos commits ou nos exemplos (veja a [Política de Segurança](SECURITY.md)).

## Padrão de commits

Mensagens curtas e no imperativo, em português, com um prefixo opcional:

- `feat:` nova funcionalidade
- `fix:` correção de bug
- `docs:` documentação
- `chore:` manutenção
